How the Tour Manager Finance page works

A plain-language guide for QA and stakeholders

Access

Finance is a separate Tour Manager area. A Finance account opens /tour-manager/finance and sees the workspace and season context.

Revenue report

The Revenue view lists collected and refunded transactions for NetSuite and Stripe. The filters narrow the report by month, tour, region, event and product. The page states that months use Pacific Time.

Insurance report

The Insurance view switches the report to insurance-related collections and refunds. It uses the same report controls and download workflow.

Downloads

Download CSV exports the filtered transaction data. Download payout tie-out provides one row per Stripe payout with its lines, gross amount, Stripe fees and expected payout.
