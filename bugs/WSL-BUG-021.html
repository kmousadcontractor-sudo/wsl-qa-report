WSL-BUG-021 � Google address selection leaves the Location timezone empty

Test case: com.worldsurfleague.registration.tests.ChecklistP0E2ETest.checklistADD45

Severity / Priority: Medium / P2 (proposed)

Classification: Observed application failure; root cause requires developer confirmation

What happened

City and ZIP were populated, but the Location timezone selector stayed blank.

What should happen

Selecting the Mountain View address sets the Location timezone to America/Los_Angeles.

Why it matters

An incomplete timezone can lead to incorrect event-time setup.

What needs to be done

Populate the Location timezone from the selected address, or surface a clear manual selection if lookup fails. Verify this in Location only, not athlete details.

Steps to reproduce

  1. Open the Tour Manager Location form used by the test.
  2. Select the Mountain View address from the Google address suggestions.
  3. Inspect the populated city, ZIP and timezone fields.

Environment: WSL dev. Run started: 2026-10-14T21:04:55.336Z. Results and evidence are retained from that execution; this wording update did not rerun the test.

Original check result and recorded scenario steps

Original expected: Selecting the Google address fills the location timezone with America/Los_Angeles (Pacific time).

Original actual: The location timezone selector remained blank after selecting the Mountain View address.

  2. POST /auth/register returned HTTP 201.
  3. POST /auth/login returned HTTP 200.
