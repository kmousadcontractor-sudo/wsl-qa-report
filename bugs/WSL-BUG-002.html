WSL-BUG-002 � Other event cards still offer Register after the Single Event credit is used

Test case: com.worldsurfleague.registration.tests.AthleteRegistrationThroughEventEntryE2ETest.athleteRegistration_throughEventEntry

Severity / Priority: High / P1 (proposed)

Classification: Observed application failure; root cause requires developer confirmation

What happened

Of 10 other actionable event cards, 4 still showed Register and 6 showed Upgrade membership.

What should happen

After the one Single Event credit is consumed, every other actionable event card shows Upgrade membership instead of Register.

Why it matters

The athlete is offered a registration action after their only credit has been used.

What needs to be done

Use the consumed-credit state consistently across all other event cards. Show Upgrade membership and route to upgrade rather than another entry form. This execution counted card actions; it did not establish that another entry could be completed.

Steps to reproduce

  1. Complete a Single Event membership purchase.
  2. Register for one event to consume the credit.
  3. Return to the Event List.
  4. Inspect the action on each other event card.
