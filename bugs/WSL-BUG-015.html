WSL-BUG-015 � Terms is cleared after refreshing registration

Test case: com.worldsurfleague.registration.tests.BackRefreshE2ETest.refreshPreservesEnteredData

Severity / Priority: Medium / P2 (proposed)

Classification: Observed application failure; root cause requires developer confirmation

What happened

The Terms checkbox was no longer selected.

What should happen

The previously selected Terms checkbox stays selected.

Why it matters

The user must re-enter information or select consent again to continue.

What needs to be done

Preserve the relevant draft value across this navigation, or confirm and document that resetting it is intended.

Steps to reproduce

  1. Open athlete registration and enter date of birth 07/07/2000.
  2. Continue to Account creation, fill the required account fields and accept Terms.
  3. Refresh the page. If it returns to Age gate, inspect the date of birth and continue back to Account creation.
  4. Inspect terms.
