WSL-BUG-001 — Already-open event card still shows Register after the athlete is waitlisted

Status: Failed — tracked in Jira WSL-9578 (Already-open event cards do not update after waitlisting).

Test case: com.worldsurfleague.registration.tests.AthleteRegistrationThroughEventEntryE2ETest.athleteRegistration_throughEventEntry

Severity / Priority: Medium / P2 (proposed)

Classification: Observed application failure; root cause requires developer confirmation

What happened

The test verified waitlisting, but the retained card still showed Ready for entries and Register during its observation window.

What should happen

The already-open card updates to Waitlisted without refreshing or navigating away.

Why it matters

The athlete sees an outdated Register action and cannot tell from that card that their entry is waitlisted.

What needs to be done

Update or invalidate the retained Event List data after entry creation. Verify the same athlete, event and entry when checking the card.

Steps to reproduce

  1. Keep the athlete Event List open in one tab.
  2. Register the same athlete for the QA event in another tab.
  3. Verify the returned entry is waitlisted.
  4. Observe the original Event List tab without refreshing it.
