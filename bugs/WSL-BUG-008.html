WSL-BUG-008 � Password is cleared after Back and Continue

Test case: com.worldsurfleague.registration.tests.BackRefreshE2ETest.backAndContinuePreserveEnteredData

Severity / Priority: Medium / P2 (proposed)

Classification: Observed application failure; root cause requires developer confirmation

What happened

The assertion did not find the originally entered password in the field.

What should happen

Under the current test expectation, the entered password remains available. Confirm whether retaining it is intended before changing the application.

Why it matters

The user must re-enter information or select consent again to continue.

What needs to be done

Confirm the password-retention requirement and align the assertion with the agreed secure behavior. Do not persist passwords solely to satisfy this check.

Steps to reproduce

  1. Open athlete registration and enter date of birth 07/07/2000.
  2. Continue to Account creation, fill the required account fields and accept Terms.
  3. Select Back to return to Age gate, then Continue to Account creation.
  4. Inspect password.
