Copy by date range: test report

Tour Manager → Events → Copy season, Dev, 18 Nov 2026. New: copy events between two dates into a new or an existing season. Rules: an event is copied when its start and end dates both fall inside the range (QA lead, 18 Nov); Hal (18 Nov): whatever season it belongs to; a tour is copied with only its in-range events; the season overlap rule is relaxed.

Issues and questions

  • A6 Range with no events (7–14 Apr 2026): Shows 0 tours / 0 events and "No event starts and ends inside these dates." but the "Copy season" button stays ENABLED (new-season mode). Not clicked, so we did not check whether it would create an empty season.
  • A7 From after To (10 May → 1 May): API: 422 "Choose both dates of the range to copy, the end on or after the start." UI: Copy button disabled but NO message is shown, and the summary still shows the whole season (5 tours, 210 events, 210 of 210 listed).
  • A8 Range across two seasons (1 Dec 2026 – 30 Jun 2027): Only the source season's events (94 from 2026-27, last 22 Mar 2027). From source 2027-28 the same range gives only 2027-28 events (40). The Source season picker takes one season only (2029, 2027-28, 2026-27, 2025-26); no UI picks events from several seasons.
  • C1b Name vs dates consistency: Preview accepts "2031" with dates 1 Jan–31 Dec 2032, and "2031-33" (three years) with 2031-04-01..2033-03-31.
  • E5 Untick events before copying: Unticking North Narrabeen PJ Women: list shows "5 OF 6", button "Copy 5 events", POST sends excludedEventIds=[that id], and 5 were copied ("1 event left out"). But the "What will be created" box still says "6 events" after unticking.
  • F3 History shows the copy: Each copy's History shows "18 Nov 07:09 PT · T. Manager 101 · Copied as Draft from CT-2026-M-001 · — → Draft". The source events and the season have no record, and nothing records "how many" (there is no season history).
  • G1 Cancelled events inside the range: The cancelled (and archived) "Ocean Beach Pro presented by Corona" (27 Jan 2027) IS listed to copy as Draft, while other archived events in the range are excluded.
  • G2 Tour grouping in the event list: Several groups have the same label, e.g. "Qualifying Series · Men" twice in one list. They are different tours (different ids, likely regional QS), but the region is not shown.
